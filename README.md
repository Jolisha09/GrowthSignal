
# GrowthSignal — The Lenny Growth Assistant

GrowthSignal is a full-stack AI assistant prototype for product management and growth questions. It uses React, FastAPI, and a locally running Qwen 2.5 3B model through Ollama.

## Current Features

- Editorial-style responsive React interface.
- FastAPI backend with health and chat endpoints.
- Local inference using Ollama and Qwen 2.5 3B.
- AI-generated answers displayed in the web interface.
- Basic request validation and error handling.

## Architecture

- `client/` — React and Vite frontend.
- `server/` — FastAPI backend and API routes.
- Ollama — Local language model runtime.

## Prerequisites

- Node.js and npm.
- Python 3.11 or compatible version.
- Ollama for Windows.
- Git.

## Setup

### 1. Start the local AI model

Install Ollama from https://ollama.com/download/windows.

Pull the model:

```powershell
ollama pull qwen2.5:3b
```

Ensure Ollama is running.

### 2. Start the backend

From the project root:

```powershell
cd server
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install fastapi "uvicorn[standard]" python-dotenv pydantic requests
python -m uvicorn main:app --reload
```

Backend URLs:

- Health: http://127.0.0.1:8000/health
- API documentation: http://127.0.0.1:8000/docs

### 3. Start the frontend

Open another terminal:

```powershell
cd client
npm install
npm run dev
```

Open the local URL printed by Vite.

## Configuration

The current backend defaults to:

- Ollama URL: `http://localhost:11434`
- Model: `qwen2.5:3b`

The frontend currently calls the FastAPI backend at `http://127.0.0.1:8000`.

## Current Limitations

This is an MVP, not yet the complete requested assessment solution.

- Transcript ingestion, retrieval, and source citations are not implemented.
- PostgreSQL conversation persistence and independent chat sessions are not implemented.
- The required Claude Agent SDK or Pi Coding Agent integration is not implemented.
- Cloud-provider switching is not implemented.
- The Ship 30 for 30 writing skill and secure artifact viewer are not yet complete.
- Automated tests, production deployment, and one-command startup need further work.

The current AI responses are generated by the local model and should not be treated as verified transcript-grounded answers.

## Security

Never commit API keys, passwords, `.env` files, or other secrets. Treat model-generated content as untrusted input.
